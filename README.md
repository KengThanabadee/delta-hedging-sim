# Delta Hedging Bot

A research project working toward an automated delta-hedging bot for BTC options.

The current implementation uses simulation and a historical BTC price-path experiment to develop and evaluate the hedging logic.

> **Current stage:** Monte Carlo simulation and historical price-path experiments.

## Current Experiment

The project studies the P&L and tail risk of discrete delta hedging under modeled volatility and transaction costs. The current simulation also compares different hedge frequencies.

It currently includes:

- Monte Carlo simulation of generic asset-price paths under geometric Brownian motion (GBM), used as a simplified proxy for BTC
- Black-Scholes option pricing and Greeks
- Discrete delta rebalancing with transaction fees
- VaR and CVaR summaries of simulated hedging P&L
- Historical BTC/USDT price loading from Binance
- Historical BTC/USDT spot-path analysis using rolling realized volatility

`simulation.ipynb` runs the Monte Carlo experiments. It also retains an earlier gamma-hedging experiment; current development focuses on delta hedging. `backtest.ipynb` replays the delta-hedging logic over a historical BTC/USDT spot path, with option values and deltas generated by Black-Scholes.

## Method and Assumptions

- The hedged position is a short European call or put.
- Option values and deltas are calculated with the Black-Scholes model.
- The hedge is rebalanced at discrete intervals rather than continuously.
- Transaction costs are represented by a proportional fee on hedge trades.
- Simulated price paths follow GBM.
- VaR and CVaR are calculated across the simulated terminal P&L distribution.
- The historical experiment uses BTC/USDT spot closes and rolling realized volatility as model inputs.

This scope isolates the effects of hedge frequency, modeled volatility, and transaction costs on delta-hedging behavior.

## Run the Project

Install the dependencies:

```bash
python -m pip install numpy scipy pandas matplotlib requests jupyter pytest
```

Run the test suite:

```bash
python -m pytest
```

Start Jupyter:

```bash
jupyter notebook
```

From Jupyter, open `simulation.ipynb` or `backtest.ipynb`.

The historical experiment downloads public BTC/USDT candle data from the Binance API and therefore requires an internet connection.
